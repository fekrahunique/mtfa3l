# متفاعل

منصة الأنشطة المدرسية لرواد ورائدات النشاط في المدارس الحكومية والأهلية، لمرحلتي الابتدائي والمتوسط، بنين وبنات.

**الحالة: نسخة تجريبية قيد التطوير.** الواجهة مكتملة، وربط محتوى الوزارة بدأ ولم يكتمل — اقرأ [أين وصلنا](#أين-وصلنا) قبل أي عمل.

## المبدأ الذي يحكم هذا المشروع

> **المحتوى يُلعب، لا يُعرض.**

هذا أهم درس في المشروع، وجاء بعد خطأ حقيقي: أول ربط للوحة التحكم عرض محتوى الوزارة كقوائم نقطية أنيقة — ورُفض تمامًا وبحق.

ملف الوزارة يقول: «الطلاب يعلّقون أوراقهم على الشجرة لتكتمل لوحة جماعية». الترجمة الصحيحة ليست فقرة تصف ذلك، بل **شجرة تُرسم على الشاشة وورقة تطير وتلتصق بغصنها**.

عند إضافة أي ركن جديد اسأل: ما التجربة التي يصفها هذا النص؟ ثم ابنِها.

قواعد مصاحبة:

- **الهوية البصرية تُؤخذ من ملف المناسبة نفسه**، لا من ألوان المنصة. أسبوع اليوم الوطني يأخذ الأخضر العميق ونقش السدو وشعار «عزّنا بطبعنا».
- **لا نص عربي داخل مشهد ثلاثي الأبعاد.** النصوص المرسومة كنسيج تتشوّه مع البُعد وتتزاحم مع العناصر. كل الكلام في طبقة DOM فوق المشهد.
- **لا تُخترع أرقام أو محتوى.** ما لا يُقرأ من المصدر يُسجَّل `null` ويُدرج في `unreadable`.

## استخراج ملفات الوزارة

### العقبة

خطوط ملفات الوزارة بلا خريطة Unicode. جُرّبت أربع طرق:

| الطريقة | النتيجة |
|---|---|
| نص الـ PDF عبر موصّل درايف | **معكوس**: `ةيبلاطلا ةطشنلأا جمارب` |
| عكسه برمجيًا | **غير آمن** — `لاجملا` قد تكون «المجال» أو «لامجلا»، ولا سبيل للتمييز بين ألف-لام التعريف وحرف «لا» |
| تحويل إلى Google Docs | **فشل** — نص غير مرتب مع حذف |
| `pdftotext` | **فراغات فقط** |

### الحل

رسم الصفحات صورًا بـ pdf.js داخل كروم، ثم قراءتها كما هي مطبوعة.

```bash
node tools/render-pdf.mjs "ministry-files/الفترات اللاصفية - الاستراحات - ابتدائي/sixthweekbreak-722.pdf" 1 10
```

المخرجات في `tools/rendered/<اسم الملف>/page-NN.png`.

### الملفات المصدر

تُنزَّل من درايف المالك إلى `ministry-files/` (مستثناة من git). التفاصيل في [ministry-files/README.md](ministry-files/README.md).

**١٠٧ ملفات** موزعة على ١٦ مجلدًا: ٦ مجالات للأنشطة الطلابية + نوعان من الفترات اللاصفية، لكل منهما مرحلتان.

### بنية ملف الاستراحة

```
ملف الأسبوع
├─ غلاف: رقم الأسبوع، المناسبة، الشعار، المرحلة
└─ لكل يوم:
   ├─ صفحة فاصلة: اسم الركن + رقم اليوم
   ├─ صفحة معلومات: نواتج التعلم، القيم، الروتين اليومي، المدة، المكان، الأدوات
   └─ صفحة إجراءات: خطوات التنفيذ، وأحيانًا أسئلة بإجاباتها
```

ملف من ١٠ صفحات = غلاف + ٣ أيام × ٣ صفحات. للاختصار: اقرأ الصفحات ١، ٣، ٤، ٦، ٧، ٩، ١٠ وتخطَّ الفواصل — اسم الركن يظهر في ترويسة صفحات المحتوى.

### خطوات إضافة أسبوع جديد

1. `node tools/render-pdf.mjs "<مسار الملف>" 1 <عدد الصفحات>`
2. اقرأ الصور وانقل الحقول إلى `src/data/breakPeriods.ts`.
3. حدّد `play` لكل ركن، وابنِ تجربته في `src/activities/` إن لم تكن موجودة.
4. أي قيمة غير مقروءة → `null` + أدرجها في `unreadable`.

## مزالق معروفة

| المشكلة | السبب والحل |
|---|---|
| **الأرقام تظهر «TRIAL FONT»** | خط Arsenica التجريبي لا يتضمن أرقامًا. لا تستخدم `font-display` مع أي رقم — استخدم الخط الأساسي مع `font-bold`. |
| **أصناف Tailwind تختفي** | لا تبنِ اسم الصنف ديناميكيًا (`accent.replace("text-","bg-")`). Tailwind يحذف ما لا يكتشفه وقت البناء. مرّر الصنف صريحًا. |
| **النص العربي يتمدد على canvas** | نسبة النسيج يجب أن تطابق نسبة السطح تمامًا، مع `ctx.direction = "rtl"`. |
| **خادم Vite يسقط بـ EBUSY** | مراقبة `ministry-files` أثناء التنزيل. مستثنى في `vite.config.ts`. |
| **العنوان يغطي محتوى المشهد** | ضع العنوان خارج الحاوية المثبّتة (sticky) ليمر مرة ويزول. |

## ملاحظات تقنية

- **التحقق البصري:** المعاينة داخل بيئة التطوير لا تُركّب إطارات، فلا تُلتقط لقطات. التحقق يتم بتشغيل كروم عبر `puppeteer-core` والتقاط لقطات فعلية، ثم إزالة الأداة.
- **الأداء:** الأشجار والمباني وخطوط الأسفلت مرسومة بـ `InstancedMesh`، والظلال معطّلة. أوامر الرسم ≈ ٧٦ لكل إطار، والمثلثات ≈ ١٨ ألف.
- **الحركة:** كل الانتقالات تستخدم `cubic-bezier(0.32, 0.72, 0, 1)`، وكشف التمرير عبر `IntersectionObserver` أو `whileInView` — لا `window.addEventListener('scroll')`.
- **RTL:** الصفحة `dir="rtl"` و`lang="ar"`.
- **الخطوط:** Arsenica Arabic للعناوين والشعار، Thmanyah Sans للنصوص والأرقام.
