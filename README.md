# متفاعل

منصة الأنشطة المدرسية لرواد ورائدات النشاط في المدارس الحكومية والأهلية، لمرحلتي الابتدائي والمتوسط، بنين وبنات.

**الحالة: نسخة تجريبية قيد التطوير.** الواجهة مكتملة، ومحتوى الأنشطة المعروض فيها ما زال تجريبيًا — اقرأ [حالة المحتوى](#حالة-المحتوى-مهم) قبل أي عرض خارجي.

---

## التشغيل

```bash
npm install
```

```bash
npm run dev
```

يفتح على `http://localhost:5173`.

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج (يشمل فحص الأنواع) |
| `npm run preview` | معاينة نسخة الإنتاج |
| `npm run lint` | فحص الشيفرة |

---

## التقنيات

- **Vite + React 19 + TypeScript**
- **Tailwind CSS v4** — التوكنات في `src/index.css` داخل `@theme`
- **Framer Motion** — الحركة وربط التمرير بالمشاهد
- **React Three Fiber + three.js** — المشاهد ثلاثية الأبعاد
- **read-excel-file + mammoth** — قراءة ملفات الطلاب (xlsx / docx)

## بنية المشروع

```
src/
├─ components/
│  ├─ three/            المشاهد ثلاثية الأبعاد وإعداداتها
│  ├─ dashboard/        مكوّنات لوحة التحكم
│  └─ illustrations/    رسومات SVG
├─ sections/            أقسام الصفحة الرئيسية
├─ pages/               الصفحات والتوجيه
├─ data/                نموذج بيانات الأنشطة (من ملفات الوزارة)
└─ lib/                 أدوات مساعدة وبيانات تجريبية
```

### المشاهد ثلاثية الأبعاد

كل مشهد يُحمّل عند الحاجة فقط (lazy)، ويرجع تلقائيًا لتصميم بطاقات عادي لمن فعّل **تقليل الحركة** في نظامه.

| المشهد | القسم | الفكرة |
|---|---|---|
| `DrivingScene` | الواجهة الرئيسية | قيادة سيارة من منظور السائق، مساران ذهاب وإياب |
| `RoadJourney` | المزايا | طريق يتلوى، لوحة خشبية عند كل ميزة |
| `SchoolGate` | كيف تعمل | دخول من بوابة المدرسة، أعمدة مرقّمة في الفناء |
| `RunTrack` | رحلة التسجيل | مضمار جري وشخصية بأسلوب ماين كرافت |
| `Classroom` | الأسئلة الشائعة | فصل دراسي، السبورة تعرض سؤالًا وجوابه |

**قاعدة مهمة:** لا يُكتب أي نص عربي داخل المشهد ثلاثي الأبعاد. كل الكلام في طبقة DOM فوق المشهد، لأن النصوص المرسومة كنسيج تتشوّه مع البُعد وتتزاحم مع العناصر.

## حالة المحتوى (مهم)

### ما هو حقيقي

`src/data/` يحوي بيانات منقولة من ملفات الوزارة الرسمية:

- `schema.ts` — نموذج البيانات مطابق لبنية ملفات **برامج الأنشطة الطلابية، نسخة تجريبية ١٤٤٧-٢٠٢٥**: نواتج التعلم، أساليب التقويم، المدة، مكان التنفيذ، وقت التنفيذ، مسؤولية التنفيذ، الدعم والمساندة، أدوات التنفيذ، هدف النشاط.
- `scouting-middle.ts` — **٧ برامج** من المجال الكشفي للمرحلة المتوسطة، كل سجل مربوط برابط ملفه المصدر في الدرايف.

**قاعدة النزاهة:** أي قيمة لم تُقرأ بوضوح من المصدر تُسجَّل `null` وتُدرج في حقل `unreadable` — لا تُخمَّن أبدًا.

### ما هو تجريبي مؤلَّف

- `src/lib/dashboardData.ts` — الأنشطة الستة والأدوات الأربعة في لوحة التحكم **مؤلَّفة بالكامل** ولا علاقة لها بملفات الوزارة.
- عدّاد المستهدف الأسبوعي (٢ من ٥) رقم ثابت لا أساس له.

> أي عبارة تدّعي أن المنصة «مبنية على الملفات الرسمية» أُزيلت من الواجهة والأسئلة الشائعة. لا تُعِدها قبل اكتمال الربط الفعلي.

## استخراج ملفات الوزارة — العقبة والحل

الملفات في درايف المالك، منظّمة في ١٦ مجلدًا (٦ مجالات + نوعان من الفترات اللاصفية × مرحلتين)، بأكثر من **١٠٠ ملف PDF**.

### ما لا ينفع

| الطريقة | النتيجة |
|---|---|
| نص الـ PDF المدمج | يخرج **معكوسًا**: `ةيبلاطلا ةطشنلأا جمارب` |
| عكسه برمجيًا | **غير آمن** — `لاجملا` قد تكون «المجال» أو «لامجلا»، ولا سبيل من النص وحده للتمييز بين ألف-لام التعريف وحرف «لا» |
| التحويل إلى Google Docs | **جُرّب وفشل** — النص غير مرتب ومع حذف، لأن قوقل استخدم طبقة النص المعطوبة نفسها |

### ما ينفع

تنزيل الملفات محليًا وقراءة الصفحات **مرسومة كصور**، فيُقرأ العربي كما يقرأه إنسان — بلا طبقة نص معطوبة وبلا حذف.

```
ministry-files/          ← ينزَّل من الدرايف، مستثنى من git
```

### الخطوة التالية

1. تنزيل مجلدات الدرايف إلى `ministry-files/`.
2. البدء بـ **الاستراحات** — ملفاتها مرتّبة بالأسبوع أصلًا (الخامس، السادس، التاسع… السادس عشر)، وهي ما يجعل «المستهدف الأسبوعي» حقيقيًا بدل الرقم الثابت الحالي.
3. ثم **المجال الكشفي** كاملًا، وإعادة بناء لوحة التحكم على بيانات حقيقية.
4. التوسّع لبقية المجالات على دفعات.

## ملاحظات للمطوّرين

- **التحقق البصري:** المعاينة داخل بيئة التطوير لا تُركّب إطارات، فـ `ResizeObserver` لا يعمل ولا تُلتقط لقطات. التحقق تم بتشغيل كروم محليًا عبر `puppeteer-core` والتقاط لقطات فعلية، ثم إزالة الأداة.
- **الأداء:** الأشجار والمباني وخطوط الأسفلت مرسومة بـ `InstancedMesh`، والظلال معطّلة. أوامر الرسم ≈ ٧٦ لكل إطار، والمثلثات ≈ ١٨ ألف.
- **الحركة:** جميع الانتقالات تستخدم `cubic-bezier(0.32, 0.72, 0, 1)`، وكشف التمرير عبر `IntersectionObserver` أو `whileInView` — لا `window.addEventListener('scroll')`.
- **RTL:** الصفحة `dir="rtl"` و`lang="ar"`. أي نص يُرسم على canvas يحتاج `ctx.direction = "rtl"` وأبعاد نسيج مطابقة لأبعاد السطح، وإلا يتمدّد أفقيًا.
