# ملفات الوزارة

هذا المجلد يستقبل ملفات **برامج الأنشطة الطلابية** المنزَّلة من الدرايف.

**محتوياته لا تُرفع إلى GitHub** — مستثناة في `.gitignore`، ويبقى هذا الملف فقط للتوضيح.

## طريقة التنزيل

1. افتح درايف الحساب المالك.
2. حدّد المجلدات الثمانية التي تبدأ بـ **الأنشطة الطلابية** و**الفترات اللاصفية**.
3. كليك يمين ← **تنزيل**. سيُنشئ قوقل ملف zip.
4. فُك الضغط داخل هذا المجلد مباشرة.

## ليش محليًا وليس من الدرايف مباشرة

نص الـ PDF المدمج يخرج معكوسًا (`ةيبلاطلا ةطشنلأا جمارب`)، وعكسه برمجيًا غير آمن،
وتحويله إلى Google Docs جُرِّب وأخرج نصًا غير مرتب مع حذف.

الطريقة الموثوقة الوحيدة هي قراءة صفحات الـ PDF **مرسومة كصور**، وهذا يتطلب
وجود الملفات على الجهاز.
